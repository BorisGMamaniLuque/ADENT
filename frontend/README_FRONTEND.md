# ADENT Frontend estructurado

Frontend React + Vite reorganizado para facilitar cambios de funcionalidades, roles, endpoints y UX/UI.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Docker

El Dockerfile y `nginx.conf` se conservan para funcionar con el `docker-compose.yml` general de ADENT.

Consulta `docs/FRONTEND_GUIDE.md` antes de modificar roles o agregar módulos.
